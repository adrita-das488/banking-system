# banking-system
creating accounts with pin and with four specialised functions 

Simple Banking System:

A terminal-based banking program in Python. Customers can create an account with a 4-digit PIN, check balance, deposit and withdraw money. The PIN is required for every transaction.

Run:

python bank.py

Usage:

- Enter your name (new users can create an account and set a PIN).
- Choose from the menu: 1 Balance, 2 Deposit, 3 Withdraw, 4 Exit.
- Admin login (admin123,pin:123456) closes the program and shows all balances.

Note:

Data is stored in dictionaries, so it is lost when the program ends.
